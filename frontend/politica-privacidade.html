  • Cumprir obrigações legais e regulatórias.

6. Com quem compartilhamos dados

  • A viação contratada — recebe os dados necessários para prestar o serviço (nome, documento, contato, trecho ou trajeto).
  • Provedor de e-mail/SMTP — para envio de confirmações, quando configurado.
  • Provedor de WhatsApp — para envio de notificações, quando configurado.
  • Gateway de pagamento (ex: Mercado Pago) — para processar cobranças.
  • Serviço de monitoramento de erros (ex: Sentry) — quando configurado, recebe dados técnicos de falhas do sistema (não inclui senha).
  • Serviço de push notification — o navegador do próprio usuário (não há terceiro como Firebase envolvido; o Vion usa Web Push nativo).
  • Autoridades públicas — quando exigido por lei ou ordem judicial.

Não vendemos dados pessoais a terceiros para fins de marketing.

7. Por quanto tempo guardamos os dados

Dados de conta e transações são mantidos enquanto a conta estiver ativa e pelo prazo adicional exigido por obrigações fiscais e legais. Registros de acesso (Marco Civil da Internet) são mantidos pelo prazo mínimo legal de 6 meses. [Definir prazos exatos por tipo de dado na versão final.]

8. Seus direitos (LGPD, art. 18)

Você pode solicitar, a qualquer momento:

  • Confirmação de que tratamos seus dados, e acesso a eles;
  • Correção de dados incompletos, inexatos ou desatualizados;
  • Anonimização, bloqueio ou eliminação de dados desnecessários ou tratados em desconformidade com a lei;
  • Portabilidade dos dados a outro fornecedor;
  • Eliminação dos dados tratados com base no seu consentimento;
  • Informação sobre com quem compartilhamos seus dados;
  • Revogação do consentimento, quando aplicável.

Para exercer esses direitos, entre em contato pelo canal indicado na seção 2.

9. Segurança

Senhas são armazenadas com hash (nunca em texto puro), o acesso à conta usa autenticação por token, e o acesso aos dados de cada empresa é isolado por empresa (multi-tenant) — uma viação não acessa dados de outra.
